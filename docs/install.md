# 安装说明

泡泡栈的在线安装入口是后端站点上的 `/install`。本机 API 若跑在 `43125`，地址是：

http://127.0.0.1:43125/install

没有安装锁时，浏览器访问 `/` 会转到这个向导。`/api/v1` 返回：

```json
{
  "code": 50301,
  "message": "系统尚未安装",
  "data": { "install_url": "http://127.0.0.1:43125/install" }
}
```

## 六步

1. **环境检测**。检查 PHP 8.3 及以上、Laravel 需要的扩展，以及 `storage`、`bootstrap/cache`、`.env`、`storage/app` 是否可写。失败项用红字写明原因。Redis 是可选项：连不上会红字说明，但不阻止继续。
2. **数据库**。填写主机、端口、库名、账号和密码，先点「测试连接」。只有连接成功才能进入下一步。库不存在且账号有建库权限时，向导会创建 `utf8mb4` 库。
3. **管理员**。创建平台超管。邮箱、昵称、至少 8 位密码，并再输入一次。这个账号的 `tenant_id` 为空，不属于某个租户。
4. **站点与租户**。站点名称和地址写入 `.env` 的 `APP_NAME`、`APP_URL`。租户名称和标识写入第一套圈子，并把标识写入 `TENANT_DEFAULT_SLUG`。
5. **安装**。确认摘要后执行：写 `.env`、`migrate --force`、创建免费套餐和租户、按需 `db:seed`、写入平台超管。已有 `APP_KEY` 会保留，避免把正在使用的密钥换掉。
6. **完成**。展示安装日志，并给出健康检查、管理后台登录和用户端入口。

演示数据默认不勾选。勾选后会写入示例成员、版块、一篇已发布帖子和一个示例软件；同标识的记录会更新，不会另建一套库。本机如果已经跑过 `migrate --seed`，请不要勾选，以免把示例版块的帖子计数写回种子值。

## 安装锁

成功后写入 `backend/storage/app/install.lock`（JSON，含完成时间、超管邮箱、租户和日志）。该文件被 `storage/app/.gitignore` 忽略。

锁存在时：

- `/install` 只显示完成页，不能再填表。
- `POST /install/run` 等安装接口返回 `40901`。
- API 恢复正常。健康检查是 http://127.0.0.1:43125/api/v1/system/health 。
- 管理后台登录是 http://127.0.0.1:43124/auth/login ，用户端是 http://127.0.0.1:43126 。

要重装，先停掉站点，自行备份数据库，删除 `install.lock` 后再打开向导。页面上没有重装按钮。

## 命令行仍可用

开发机可以继续手工准备 `.env` 并执行 `php artisan migrate --seed`。这样不会自动生成安装锁。锁缺失时在线接口仍视为未安装，需要走一遍向导，或在确认数据库已经就绪后由向导写锁。向导里的迁移可以重复执行。

用 `php artisan serve` 时，向导若真的改写了 `.env`，开发服务器会重启并可能打断这一次响应。安装锁在配置写完后立刻生成。页面若中断，重新打开 `/install`：已经锁上就进入完成页；还没有锁就再执行一次，配置一致时不会再次改文件。
